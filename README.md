# Shadow Workshop — MVP 0.1

Стартовый PWA-прототип рабочей студии для проекта «Семён — Охотник теней».

## Что работает сейчас

- Адаптивный интерфейс под телефон и компьютер.
- Каталог материалов (сохраняются название, тип, описание, выбранное имя/размер файла и ссылка; байты выбранного файла не загружаются).
- Задачи с выбором связанного материала и приоритетом.
- Формирование независимых сообщений для Нокса и Ворона, копирование сообщения и открытие сохранённой ссылки на личный чат.
- Ручное сохранение каждого ответа отдельно.
- Поля для совпадений, разногласий, вопросов и таймкодов.
- Журнал решений со статусами.
- Экспорт локального журнала в JSON.
- PWA-манифест и service worker для установки и кэширования оболочки.

## Ограничения прототипа

- Данные хранятся в `localStorage` текущего браузера. Это не облачная синхронизация и не резервная копия.
- Каталог не загружает медиаданные в Drive; он сохраняет только метаданные и ссылки.
- Нет автоматического чтения/отправки сообщений в личные чаты ChatGPT. Пользователь копирует сообщение, отправляет его вручную и вставляет ответ обратно.
- Google Drive/Sheets и API моделей пока не подключены.
- Не используйте публичный GitHub для личных файлов, материалов проекта или секретов.

## Публикация через GitHub Pages

1. Создайте отдельный репозиторий GitHub для приложения. На первом этапе можно назвать `shadow-workshop`.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `service-worker.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `README.md`.
3. В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/(root)`.
4. Дождитесь адреса Pages. Откройте его на телефоне в Chrome.
5. В меню Chrome выберите **Добавить на главный экран** или **Установить приложение** (название зависит от версии браузера).
6. Откройте **Настройки** внутри приложения и вставьте ссылку на личный чат Нокса и ссылку на чат Ворона. Сохраните.
7. Создайте тестовую задачу и проверьте цикл: подготовить сообщение → скопировать → открыть чат → отправить вручную → скопировать ответ → вставить в раздел «Ответы и сравнение».

## Локальный просмотр

Можно открыть `index.html` для проверки интерфейса, но установка PWA и service worker требуют HTTPS или `localhost`. Для разработки можно запустить любой локальный статический сервер.

## Безопасность

В репозитории нет ключей API. Никогда не вставляйте секреты OpenAI/Google в `app.js` или другие публичные файлы. Будущие секретные ключи должны храниться на защищённой серверной стороне.
